Portal de Pacientes

Sistema de Gestión e Integración de Imágenes Médicas (PACS)
Organización: Ministerio de Salud Pública Estado: Versión Funcional / Producción Local
Fecha de Informe: Agosto 2026 Arquitectura: Decoupled Web App (React + .NET 8)

📐 1. Resumen Ejecutivo y Arquitectura

El Portal de Pacientes es una plataforma web responsive diseñada para permitir a los ciudadanos acceder de manera ágil, segura y directa a sus estudios médicos de diagnóstico por imágenes (radiografías, tomografías, ecografías, mamografías, etc.) y descargar sus informes médicos oficiales emitidos en los diferentes efectores de la provincia.

🛠️ 2. Tecnologías Utilizadas

Frontend

  • Framework / Librería: React 18 (Vite 8)
  • Enrutamiento: React Router (v6)
  • Componentes UI e Iconos: Lucide React, React Hot Toast
  • Seguridad: React Google reCAPTCHA v2/v3
  • Diseño y Estilos: CSS3 Orientado a Variables (`:root`, `[data-theme='dark']`), Layout Adaptativo (Flexbox/Grid), animaciones CSS y Modo Oscuro nativo persistente.

Backend

  • Plataforma: .NET 8 (C#) Web API
  • Servidor de Aplicaciones: Kestrel (`http://localhost:5075`)
  • Comunicación HTTP: `HttpClient` con soporte asíncrono y tareas en paralelo (`Task.WhenAll`).

Integraciones y Servicios

  • PACS Pentalogic: Consumo de endpoints REST (`getstudylist.php`, `getstudyurl.php`, `getinformeurl.php`).
  • Sistema Genexus (SGC/SGH):** Capa de servicio preparada para mapeo de pacientes y efectores.
  • Seguridad Anti-Bot: Validación de credenciales e integración de reCAPTCHA.

✨ 4. Funcionalidades Clave Implementadas

4.1. Autenticación y Cierre Automático por Inactividad

  • Ingreso dinámico mediante DNI y Número de Estudio (Accession Number).
  • Cierre de sesión automático tras 15 minutos de inactividad detectando interacción del usuario.

4.2. Tarjetas de Estudio e Historial Unificado

  • Visualización del estudio actual e historial completo de los últimos 10 años.
  • Indicadores de Estado: LISTO (informe disponible) y PROCESO (estudio en elaboración).

4.3. Filtros y Búsqueda Inteligente

  • Filtro de 3 Estados: Botón toggle entre [Todos], [Con informe] y [Sin informe].
  • Búsqueda Multi-Criterio: Filtra en tiempo real por nombre de estudio, número de acceso, efector/hospital y fecha en múltiples formatos (ISO, DD/MM/YYYY, meses en español).

4.4. Experiencia Móvil y Modo Oscuro

  • Visor Móvil PDF: Abre el PDF directamente en pantalla completa para optimizar en iOS y Android.
  • Modo Oscuro (Dark Mode): Toggle en el encabezado con paleta de colores ajustada (`#0b1120`, `#1e293b`).

🔗 5. Endpoints de API (.NET Web API)

Método Endpoint Descripción
POST /api/auth/login Validación de credenciales y reCAPTCHA con el servidor PACS.
GET /api/study/current Obtiene los detalles y enlaces del estudio actual.
GET /api/study/history Consulta y compila el historial unificado del paciente (10 años).
GET /api/study/download-report Genera la descarga directa del informe médico en formato PDF.
